## 📌 Featured Engineering Projects

### 🫀 [Cordex](https://github.com/kai-deun/Cordex) — AI-Powered Cardiac Risk Assessment App
* **Tech Stack:** Next.js, FastAPI, PostgreSQL, XGBoost, PyTorch, SHAP, Grad-CAM
* A registration-free clinical tool fusing a Next.js dashboard and a FastAPI backend to run dual-layer prognostic ML pipelines. It leverages tabular ensemble models alongside a DenseNet121 computer vision architecture to output real-time visual cardiac risk heatmaps via Grad-CAM localization.

### 📰 [Fake News Detector](https://github.com/kai-deun/Fake-News-Detector) — Cross-Lingual Misinformation Classifier
* **Tech Stack:** Python, PyTorch, Hugging Face (Transformers), XLM-RoBERTa, FastAPI, Streamlit
* A transformer-driven platform fine-tuned on bilingual (English, Filipino, and Taglish) snippets. Achieved a **71.8% generalization accuracy** on Filipino and Taglish bilingual snippets while returning real-time credibility ratings and attention-weighted token attributions to deliver a frictionless, transparent user experience.

### ⚡ [NoteShare](https://github.com/kai-deun/NoteShare) — Zero-Dependency Note-Sharing Platform
* **Tech Stack:** C11, WinSock2, Windows API, HTML5/CSS3
* Built entirely from scratch in C with zero external dependencies. Features a custom HTTP/1.1 parser, server-side template rendering, and an atomic flat-file persistence system that handles multi-user session authentication with sub-millisecond latency.

### 🕹️ [Logic Gate Game](https://github.com/kai-deun/Logic-Gate-Game) — Interactive Circuit Simulator
* **Tech Stack:** C11, Mongoose HTTP Server, Win32 API, SVG, HTML/CSS
* A full-stack logic circuit engine written in C that serves assets natively from memory. Includes a dynamic HTML5/SVG front-end canvas and a Win32 hot-reloading auto-compiler for interactive execution.
